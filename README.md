# Minimal Academic Homepage

A simple static academic homepage for GitHub Pages.

## Use

1. Replace `your-github-username` in `index.html`.
2. Replace `your.email@fsu.edu` with your academic email.
3. Replace the eight publication placeholders with your exact Google Scholar publication metadata.
4. Put your CV at `assets/cv.pdf` if you want the CV link to work.
5. Upload these files to a repository named `YOUR_USERNAME.github.io`.
6. In GitHub: Settings → Pages → Deploy from branch → main / root.

## Files

- `index.html` — page content
- `styles.css` — visual design
- `assets/profile-placeholder.png` — temporary profile image
